Проект для обладателей библиотек бумажных книг, помогает вести учёт и быстро находить есть ли книга и её местонахождение.
Это помогает книголюбам не покупать двойные экземпляры и сохранять впечатления от прочитанного.

**Основные возможности**:
- Добавление, удаление, обновление и поиск книг, добавление авторов
- Пакетное добавление книг с автоматическим созданием авторов при необходимости
- Кэширование авторов
- Поддержка многопоточности
- Интеграционные тесты (TestContainers)
- Тесты с kafka (TestContainers)

**Технологический стек**
- Java 21
- Spring Boot 3.5.11
- Spring Data JPA / Hibernate
- PostgreSQL
- Lombok
- Spring Cache
- Spring Web
- Spring Kafka (в тестовой части)
- Testcontainers + Doker (для интеграционного тестирования)
- OpenAPI (springdoc-openapi) для документации API
